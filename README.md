# 🎂 ربات تلگرام یادآور تولد

رباتی که تاریخ تولد کاربرها رو ذخیره می‌کنه و هر روز بهشون پیام می‌فرسته که چند روز تا تولدشون مونده.

## ساختار پروژه

```
birthday_bot/
├── main.py          # نقطه ورود — راه‌اندازی ربات
├── config.py        # خواندن تنظیمات از .env
├── database.py      # لایه دیتابیس (SQLite)
├── handlers.py      # هندلرهای دستورات
├── jobs.py          # جاب یادآوری روزانه
├── admin.py         # پنل ادمین (آمار، قفل کانال، پیام همگانی)
├── channel_lock.py  # قفل عضویت اجباری در کانال
├── sender.py        # ارسال انبوه با کنترل نرخ
├── utils.py         # توابع کمکی تاریخ
├── .env.example     # نمونه فایل تنظیمات
├── .gitignore
├── requirements.txt
└── README.md
```

## راه‌اندازی

۱. نصب نیازمندی‌ها:

```bash
pip install -r requirements.txt
```

۲. ساخت فایل تنظیمات:

```bash
cp .env.example .env
```

بعد فایل `.env` رو باز کن و توکن رباتت (از [@BotFather](https://t.me/BotFather)) رو بذار.

۳. اجرا:

```bash
python main.py
```

## دستورات ربات

- `/start` — راهنما
- `/setbirthday ماه روز` — ثبت تولد (مثال: `/setbirthday 3 25`)
- `/mybirthday` — نمایش تولد و روزهای باقی‌مانده
- `/deletebirthday` — حذف تولد و توقف یادآوری

## دستورات ادمین

- `/admin` — پنل مدیریت (آمار، روشن/خاموش کردن قفل کانال)
- `/setchannel @channel` — تنظیم کانال قفل (ربات باید ادمین کانال باشه)
- `/broadcast متن` — ارسال پیام همگانی به همه کاربران

## مقیاس‌پذیری

ارسال یادآوری روزانه و پیام همگانی به‌صورت دسته‌ای (پیش‌فرض ۲۵ پیام در ثانیه) انجام می‌شه تا محدودیت تلگرام (~۳۰ پیام/ثانیه) رعایت بشه. خطای `RetryAfter` تلگرام هم مدیریت می‌شه و کاربرهایی که ربات رو بلاک کردن خودکار حذف می‌شن. دیتابیس با حالت WAL اجرا می‌شه که همزمانی خواندن/نوشتن رو بهتر می‌کنه.

## تنظیمات (.env)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات (اجباری) |
| `DB_PATH` | `birthdays.db` | مسیر فایل دیتابیس |
| `REMINDER_HOUR` | `9` | ساعت ارسال یادآوری |
| `REMINDER_MINUTE` | `0` | دقیقه ارسال یادآوری |
| `TIMEZONE` | `Asia/Tehran` | منطقه زمانی |
| `LOG_LEVEL` | `INFO` | سطح لاگ |
| `ADMIN_IDS` | — | آیدی عددی ادمین‌ها با کاما جدا شده |
| `SEND_RATE` | `25` | حداکثر پیام ارسالی در ثانیه |
